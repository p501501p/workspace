## บทคัดย่อ

Stockroom เป็นเว็บแอปพลิเคชันสำหรับจัดการข้อมูลสินค้าในคลัง พัฒนาด้วย Next.js และเชื่อมต่อฐานข้อมูล PostgreSQL ผ่าน Prisma ผู้ใช้ที่เข้าสู่ระบบสามารถดูและค้นหารายการสินค้าได้ ส่วนผู้ดูแลระบบสามารถเพิ่ม แก้ไข และลบสินค้าได้ ระบบมีการตรวจสอบข้อมูลก่อนบันทึก และรองรับการเข้าสู่ระบบด้วยอีเมลและรหัสผ่าน รวมถึง GitHub เมื่อกำหนดค่าการเชื่อมต่อ

**คำสำคัญ:** ระบบจัดการคลังสินค้า, เว็บแอปพลิเคชัน, Next.js, PostgreSQL, Prisma

## 1. ที่มาและความสำคัญ

การจัดเก็บข้อมูลสินค้าและจำนวนคงเหลือเป็นส่วนสำคัญของการบริหารคลังสินค้า หากข้อมูลกระจัดกระจายหรือปรับปรุงด้วยวิธีที่ไม่เป็นระบบ อาจทำให้การค้นหาสินค้าและการติดตามจำนวนคงเหลือทำได้ยาก โครงงานนี้จึงพัฒนาระบบเว็บสำหรับจัดเก็บ ค้นหา และจัดการข้อมูลสินค้าไว้ในฐานข้อมูลเดียว พร้อมกำหนดสิทธิ์การใช้งานสำหรับผู้ใช้ทั่วไปและผู้ดูแลระบบ

## 2. วัตถุประสงค์

1. เพื่อพัฒนาเว็บแอปพลิเคชันสำหรับจัดเก็บและแสดงข้อมูลสินค้าในคลัง
2. เพื่อให้ผู้ใช้ค้นหาสินค้าจากรหัส ชื่อ หรือหมวดหมู่ได้
3. เพื่อให้ผู้ดูแลระบบสามารถเพิ่ม แก้ไข และลบข้อมูลสินค้าได้
4. เพื่อประยุกต์ใช้ระบบยืนยันตัวตน การกำหนดสิทธิ์ และการตรวจสอบข้อมูลในแอปพลิเคชัน

## 3. ขอบเขตของระบบ

### 3.1 ขอบเขตด้านผู้ใช้งาน

- ผู้ใช้ทั่วไปสามารถสมัครสมาชิก เข้าสู่ระบบ และดูหรือค้นหารายการสินค้าได้
- ผู้ดูแลระบบสามารถจัดการข้อมูลสินค้า ได้แก่ เพิ่ม แก้ไข และลบ
- ผู้สมัครสมาชิกใหม่ได้รับสิทธิ์ผู้ใช้ทั่วไปโดยอัตโนมัติ การกำหนดสิทธิ์ผู้ดูแลระบบต้องดำเนินการโดยผู้ดูแลฐานข้อมูลหรือผู้มีสิทธิ์ที่ได้รับมอบหมาย

### 3.2 ขอบเขตด้านข้อมูลสินค้า

ระบบจัดเก็บข้อมูลสินค้า ได้แก่ รหัสสินค้า ชื่อสินค้า หมวดหมู่ ราคา จำนวนคงเหลือ และ URL รูปภาพ (ไม่บังคับ) โดยกำหนดให้รหัสสินค้าไม่ซ้ำกัน ราคาและจำนวนเป็นจำนวนเต็มที่ไม่ติดลบ

### 3.3 ข้อจำกัด

- ระบบนี้มุ่งเน้นการจัดการรายการสินค้าและจำนวนคงเหลือ ไม่ครอบคลุมการขาย การสั่งซื้อ หรือการตัดสต็อกอัตโนมัติ
- รูปภาพสินค้าใช้ URL ภายนอก ระบบไม่ได้อัปโหลดหรือจัดเก็บไฟล์รูปภาพ
- การเข้าสู่ระบบด้วย GitHub ต้องตั้งค่า OAuth credentials ก่อนใช้งาน

## 5. ภาพรวมการออกแบบระบบ

ระบบแบ่งการทำงานออกเป็น 3 ส่วนหลัก:

1. **ส่วนติดต่อผู้ใช้ (Frontend):** หน้าแรก หน้าเข้าสู่ระบบ หน้าสมัครสมาชิก และหน้าจัดการสินค้า
2. **ส่วนประมวลผล (Application/API):** Next.js Server Actions และ API Routes ทำหน้าที่ตรวจสอบสิทธิ์ ตรวจสอบข้อมูล และประสานงานกับฐานข้อมูล
3. **ส่วนจัดเก็บข้อมูล (Database):** PostgreSQL จัดเก็บข้อมูลผู้ใช้และสินค้า โดย Prisma ใช้เป็น ORM

### 5.1 โครงสร้างข้อมูล

| ตาราง | ข้อมูลสำคัญ |
| --- | --- |
| `User` | รหัสผู้ใช้ ชื่อ อีเมล รหัสผ่านที่ผ่านการแฮช บทบาท และวันเวลาสร้าง/แก้ไข |
| `Product` | รหัสสินค้า ชื่อ หมวดหมู่ ราคา จำนวนคงเหลือ URL รูปภาพ และวันเวลาสร้าง/แก้ไข |

บทบาทผู้ใช้ที่กำหนดใน Prisma ได้แก่ `ADMIN` และ `USER` อีเมลผู้ใช้และรหัสสินค้าถูกกำหนดให้ไม่ซ้ำกัน

### 5.2 API สำหรับสินค้า

| Method | Endpoint | การทำงาน | สิทธิ์ |
| --- | --- | --- | --- |
| `GET` | `/api/products` | อ่านและค้นหารายการสินค้า | ผู้ใช้ที่เข้าสู่ระบบ |
| `POST` | `/api/products` | เพิ่มสินค้า | ผู้ดูแลระบบ |
| `GET` | `/api/products/[code]` | อ่านสินค้าตามรหัส | ผู้ใช้ที่เข้าสู่ระบบ |
| `PUT` | `/api/products/[code]` | แก้ไขสินค้าตามรหัส | ผู้ดูแลระบบ |
| `DELETE` | `/api/products/[code]` | ลบสินค้าตามรหัส | ผู้ดูแลระบบ |

ข้อมูลสินค้าได้รับการตรวจสอบด้วย Zod ทั้งฝั่งฟอร์มและ API โดย API ยังคงตรวจสอบซ้ำเพื่อป้องกันข้อมูลที่ไม่ถูกต้องจากคำขอโดยตรง

## 6. การติดตั้งและเตรียมระบบ

### 6.1 สิ่งที่ต้องติดตั้ง

- Node.js รุ่นที่รองรับ Next.js 16
- npm
- ฐานข้อมูล PostgreSQL เช่น Neon

### 6.2 ขั้นตอนติดตั้ง

1. เปิด Terminal ในโฟลเดอร์ `workspace/my-app`
2. ติดตั้ง dependencies:

   ```powershell
   npm ci
   ```

3. สร้างไฟล์ `.env` ที่โฟลเดอร์หลักของโปรเจกต์ โดยใส่ค่าการเชื่อมต่อและ credentials ของตนเอง:

   ```env
   DATABASE_URL="postgresql://USER:PASSWORD@HOST/DB?sslmode=require"
   DATABASE_URL_UNPOOLED="postgresql://USER:PASSWORD@HOST/DB?sslmode=require"
   AUTH_SECRET="ใส่ค่า secret ที่สร้างขึ้นเอง"
   AUTH_GITHUB_ID="GitHub OAuth Client ID (ถ้าใช้ GitHub login)"
   AUTH_GITHUB_SECRET="GitHub OAuth Client Secret (ถ้าใช้ GitHub login)"
   ```

   `DATABASE_URL` ใช้เชื่อมต่อจากแอปผ่าน Neon adapter ส่วน `DATABASE_URL_UNPOOLED` ใช้โดย Prisma CLI ตามการตั้งค่าใน `prisma7.config.ts` ค่า GitHub OAuth ใช้เฉพาะเมื่อต้องการเปิดการเข้าสู่ระบบผ่าน GitHub

4. นำ migrations ไปใช้กับฐานข้อมูล:

   ```powershell
   npx prisma migrate deploy --config prisma7.config.ts
   ```

5. เริ่มเซิร์ฟเวอร์สำหรับพัฒนา:

   ```powershell
   npm run dev
   ```

6. เปิดเว็บเบราว์เซอร์ไปที่ [http://localhost:3000](http://localhost:3000)

> ห้ามนำไฟล์ `.env` หรือค่า secret ไปเผยแพร่หรือ commit ลง repository

## 7. วิธีใช้งานระบบ

1. เปิดหน้า `/signup` เพื่อสมัครสมาชิก
2. เข้าสู่ระบบที่หน้า `/login` ด้วยอีเมลและรหัสผ่าน หรือเลือก GitHub หากได้ตั้งค่า OAuth แล้ว
3. ไปที่หน้า `/products` เพื่อดูและค้นหารายการสินค้า
4. ผู้ดูแลระบบสามารถใช้แบบฟอร์มบนหน้ารายการสินค้าเพื่อเพิ่มหรือแก้ไขสินค้า และใช้ปุ่มลบเพื่อลบสินค้า
5. ออกจากระบบผ่านปุ่ม **ออกจากระบบ**
